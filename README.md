# بوت تنسيق صفقات Telegram وKonami — نموذج أولي

> **تنبيه مهم:** يضم هذا المستودع شيفرة للتعامل مع حسابات Telegram وKonami وبيانات اعتمادها ورموز التحقق. لا تستخدمه مع حسابات أو بيانات لا تملكها أو دون موافقة صريحة من أصحابها. الشيفرة غير مراجعة أمنيًا، ولا يثبت وجودها أنها آمنة أو مكتملة أو صالحة للاستخدام الفعلي.

## نبذة

يحتوي المستودع على نموذج بوت Python لتنسيق صفقات بين مستخدمين داخل Telegram، مع أجزاء لأتمتة متصفح Playwright والتفاعل مع واجهات Telegram وKonami، واسترجاع رموز OTP من صندوق بريد عبر IMAP. ملفات المشروع الفعلية هي `main.py` و`database.py` و`browser_automation.py` و`config.py` و`requirements.txt`.

اسم المستودع على GitHub بعد إعادة تسميته هو `telegram-konami-exchange-bot`، وهو يصف المشروع بصورة أوضح من الاسم السابق.

## ما يظهر في المصدر

- تدفقات بوت لإدارة صفقات مرتبطة بمحادثة/مجموعة Telegram، ومتابعة حالات التحقق وتجميد الصفقة.
- مسارات للتحقق من حساب Telegram وحساب Konami عبر أتمتة المتصفح، مع إدخال بيانات اعتماد ورموز تحقق.
- وظائف لتقييم الصفقة، وتخزين بيانات المستخدمين والصفقات والجلسات، وتنظيف الصفقات القديمة.
- قراءة رسائل البريد عبر IMAP لمحاولة استخراج OTP.

هذه قائمة بوظائف ممثلة في أسماء الدوال ومسارات الشيفرة، وليست تأكيدًا بأن المسارات تعمل كما هو مقصود. يتضمن المصدر تطبيقات مبسطة/توضيحية وأجزاء غير مكتملة؛ فمثلًا بعض عمليات تغيير بيانات الحساب أو الاستعادة تعيد نجاحًا شكليًا أو تعتمد على محددات واجهة افتراضية. لا تعتمد على ذلك لإتمام نقل حساب أو حمايته.

## حالة المصدر والقيود

- تقرير التدقيق يذكر خطأ مسافة بادئة في `config.py` يمنع تحليل الملف، لذلك لا يمكن اعتبار البرنامج قابلاً للتشغيل بحالته المفحوصة.
- لا توجد اختبارات أو توثيق تشغيل حالي في الملفات المفحوصة، ولم يُشغّل التطبيق أو تُنفّذ اختباراته في هذه المراجعة.
- إصدار Python المطلوب، وإعداد قاعدة البيانات الفعلي، وسلوك استعادة البيانات، وسلامة تدفقات الحسابات غير محددة بما يكفي لتأكيدها.
- يوجد ملف `requirements.txt`، لكنه لا يثبت توافق الإصدارات أو قابلية التثبيت أو التشغيل.
- لم يُعثر على ملف ترخيص ضمن ملفات المستودع المفحوصة؛ لا يُفترض ترخيص أو إذن لإعادة الاستخدام.

## الإعداد والتشغيل

لم تُوثّق طريقة إعداد مكتملة في المستودع. يحتوي `config.py` على إعدادات يستوردها المصدر، إلا أن خطأ المسافة البادئة المذكور أعلاه يمنع اعتباره إعدادًا صالحًا قبل إصلاحه ومراجعته. لذلك لا تُقدَّم هنا أوامر تشغيل على أنها قابلة للتنفيذ.

الأسماء التي تشير إليها الشيفرة كمتغيرات إعداد هي: `BOT_TOKEN`، `ADMIN_IDS`، `BROWSER_EXECUTABLE_PATH`، `BROWSER_HEADLESS`، `EMAIL_ADDRESS`، `EMAIL_DOMAIN`، `EMAIL_PASSWORD`، `IMAP_PORT`، `IMAP_SERVER`، `OTP_WAIT_SECONDS`، `SESSIONS_DIR`.

إذا جرى إعداد المشروع مستقبلًا، فيلزم أولًا إصلاح خطأ الصياغة، وتحديد إصدارات Python والحزم والمتصفح وطريقة تخزين قاعدة البيانات والجلسات، ثم التحقق محليًا من كل تدفق باستخدام حسابات اختبار مصرح بها. **لم تُجرّب أي خطوات إعداد أو تثبيت أو تشغيل هنا.** لا تضع أسرارًا حقيقية في المستودع أو السجلات أو المحادثات؛ استخدم مخزن أسرار مناسبًا، ودوّر أي بيانات اعتماد سبق نشرها.

## الأمن والخصوصية

يتعامل هذا النوع من الشيفرات مع أرقام/حسابات ورسائل بريد وكلمات مرور ورموز OTP وبيانات جلسات. قد تتيح هذه البيانات الوصول إلى الحسابات. كما أن `database.py` يتضمن وظائف لحفظ بيانات الجلسات، و`browser_automation.py` ينفذ تسجيل دخول عبر متصفح وIMAP.

- لا تستخدم الخدمة لجمع بيانات اعتماد أشخاص آخرين أو تغيير حساباتهم أو تجاوز ضوابط المصادقة.

- لا تشارك ملفات قاعدة البيانات أو ملفات الجلسات أو سجلات البريد. حدّد صلاحيات الوصول والاحتفاظ والحذف، واحذف بيانات الاختبار بعد استخدامها.
- أتمتة تسجيل الدخول أو تعديل الحسابات قد تخالف شروط الخدمات أو القوانين المحلية؛ تحقق من الصلاحية والموافقة والشروط ذات الصلة قبل أي استخدام.
